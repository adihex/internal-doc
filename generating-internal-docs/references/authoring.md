# Authoring and publication

Write for a defined internal audience. Put the purpose and expected outcome in metadata summary. Sections create level-two headings; task-card titles create level-three headings. Prose Markdown must not contain a level-one heading.

Use stable lowercase IDs. Local links use `[label](#id)`. Remote hyperlinks may be presented when appropriate, but embedded remote images and other external resources are rejected so output stays standalone.

## Privacy

Assume every source field and rendered page may be distributed. Exclude prompts, private chats, reasoning traces, credentials, tokens, personal data, and machine-local paths. Provenance describes the artifact, never how an agent reasoned about it.
